CLASS 6 · MATHEMATICS · GANITA PRAKASH

Chapter 1: Patterns in Mathematics

This EMKAY learning page introduces the central skill of recognising a pattern, describing its rule and explaining why the rule fits. It is supplementary learning support, not a replacement for the textbook.

What you will learn

  • How to recognise and describe a number sequence.
  • Counting, odd, even, square, triangular and cube number patterns.
  • How to solve missing-term problems step by step.
  • How visual arrangements can explain number relationships.

Worked example

Question: Find the next three terms: 2, 5, 8, 11, …

  1. Compare consecutive terms: 5 − 2 = 3.
  2. Check the pattern again: 8 − 5 = 3 and 11 − 8 = 3.
  3. The rule is to add 3 each time.
  4. Continue: 14, 17, 20.

Answer: 14, 17, 20.
