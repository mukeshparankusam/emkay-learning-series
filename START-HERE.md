# EMKAY LEARNING SERIES — Start Here

## Run locally
1. Extract the ZIP.
2. Install Node.js (LTS) if not already installed.
3. Open a terminal in this folder and run `npm start`.
4. Open the local URL printed by the server.

For GitHub Pages, upload the static website files to the repository root. The live EMKAY AI tutor needs a separate secure backend; do not put an API key in browser JavaScript.

## Content coverage
All 549 numbered PDF sections found in the supplied textbook ZIPs have a mapped original study-package draft. Each draft includes a chapter overview, learning goals, concept notes, worked approach, practice with guidance, MCQs, recall notes and a chapter test.

## Important academic note
These are first-pass drafts, not all fully verified chapter lessons. The source PDFs are authoritative for exact chapter titles, definitions, formulas, diagrams, textbook exercises and edition details. Review generated drafts before presenting them as verified teaching material. Existing detailed Class 6 packages are retained.
